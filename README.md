Website name: Perfectly Planned
About: Perfectly Planned is an event organising website.

What it does:
The website requires a user to create an account an log into their user account. From there users can add, edit and delete events. These events are categorized by timeframes and importance levels.

The webpages:
- Landing Page
- Sign Up Page
- Login Page
- Dashboard Page
- Add/Change Event Form
- Help Page
